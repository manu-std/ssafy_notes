# 전기 자동차 충전소

집 N개가 있는 마을에 전기차 충전소를 지을 때, **집 ↔ 충전소 거리 합의 최소값**을 구하는 문제.

---

## 1. 마을

- 집의 개수 N (2 ≤ N ≤ 20)
- 마을 좌표는 X, Y 모두 **-15 ~ 15** (충전소도 이 범위 안에만 지을 수 있다)
- 각 집은 위치 `(x, y)` 와 **허용 거리 `d`** 를 가진다. (1 ≤ d ≤ 30)
- 거리는 **맨해튼 거리** : `|XH - XC| + |YH - YC|`

## 2. 조건

| 조건 | 내용 |
|---|---|
| 개수 | 충전소는 **최소 개수**로, 최대 2개까지 |
| 1개 우선 | 1개로 모든 집의 허용 거리를 만족하면 **반드시 1개만** 짓는다 |
| 2개일 때 | 각 집의 거리는 **더 가까운 충전소**까지의 거리 |
| 불가능 | 2개를 지어도 허용 거리 안에 충전소가 없는 집이 있으면 `-1` |
| 위치 | **집이 있는 칸에는 충전소를 못 짓는다** |

> ⚠️ 함정: 2개를 지으면 거리 합이 더 작아지는 경우라도, 1개로 커버가 되면 **1개짜리 답을 출력해야 한다.** 개수가 먼저고 거리 합은 그 다음이다.

## 3. 제약사항

- 2 ≤ N ≤ 20
- -15 ≤ x, y ≤ 15
- 1 ≤ d ≤ 30

## 4. 입력

```
T                  // 테스트 케이스 수
N                  // 집의 개수
x y d              // 집의 위치와 허용 거리 (N줄)
... (T번 반복)
```

## 5. 출력

각 테스트 케이스마다 `#t 정답` 형식으로 한 줄씩 출력한다. (t는 1부터 시작)

---

## 6. 예제 설명

### 예제 1 — 2개가 필요한 경우 (답 2)

| 집 | 위치 | 허용 거리 |
|---|---|---|
| A | (-2, 0) | 1 |
| B | (1, 3) | 2 |

A에서 거리 1 이내인 칸은 (-1,0), (-3,0), (-2,1), (-2,-1) 뿐인데 ((-2,0)은 집이라 제외),
여기서 B까지는 최소 5라서 **1개로는 불가능**하다.
→ A 옆에 1개, B 옆에 1개를 지어 `1 + 1 = 2`.

### 예제 2 — 1개로 되는 경우 (답 3)

| 집 | 위치 | 허용 거리 |
|---|---|---|
| A | (-1, -1) | 1 |
| B | (1, 0) | 2 |

(0, -1)에 지으면 A까지 1, B까지 2로 둘 다 허용 거리를 만족한다. → `1 + 2 = 3`

---

## 7. 풀이

좌표가 31 × 31 = **961칸**뿐이라 충전소 자리를 전부 훑어도 된다.

### 전처리

집이 없는 칸마다 아래 두 개를 만들어 둔다.

- `dist[i]` : 그 칸에서 집 i까지의 맨해튼 거리
- `mask` : **허용 거리 안에 들어오는 집들의 비트마스크** (`dist[i] <= d[i]` 인 i를 켠다)

### 1단계 — 충전소 1개

`mask == (1<<N)-1` (모든 집을 커버) 인 칸들 중 `sum(dist)` 최소값.
하나라도 있으면 **여기서 끝낸다.** (2개를 보면 안 된다)

### 2단계 — 충전소 2개

두 칸 `p`, `q` 에 대해

- 커버 조건 : `mask[p] | mask[q] == full`
- 거리 합 : `sum(min(dist_p[i], dist_q[i]))` — 집마다 가까운 쪽

961칸을 전부 짝지으면 약 46만 쌍이라 그냥 돌려도 되지만, **커버 가능한 칸이 가장 적은 집(pivot)** 을 하나 고르면
두 충전소 중 하나는 반드시 그 집을 커버해야 하므로 한쪽 후보를 크게 줄일 수 있다.
(1단계에서 답이 안 나왔다는 건 어떤 집의 허용 거리가 빡빡하다는 뜻이라, pivot 후보는 보통 아주 작다.)

그 집을 커버하는 칸이 **0개면 바로 `-1`** 이다.

### 복잡도

- 전처리 : 961 × N
- 2단계 : |cover(pivot)| × 961 × N (비트마스크로 커버 안 되는 쌍은 먼저 걸러냄)

### 놓치기 쉬운 부분

1. 집이 있는 칸은 후보에서 빼야 한다.
2. 1개로 가능하면 **무조건** 1개 (거리 합 비교 금지).
3. 2개일 때 각 집은 `min(두 충전소까지의 거리)`, 두 거리를 더하는 게 아니다.
4. 충전소도 -15 ~ 15 범위 안이다.

---

## 8. 입출력 예

입력 (`input.txt`)

```
5
2
-2 0 1
1 3 2
2
-1 -1 1
1 0 2
10
3 5 4
...
```

출력 (`output.txt`)

```
#1 2
#2 3
#3 36
#4 -1
#5 21
```

> `#1`, `#2` 는 문제 지문에 나온 값(2, 3)과 일치한다. 나머지 3개는 공식 정답 파일이 없어 `solve.py` 결과를 적어둔 것이다.
> `#4` 는 허용 거리 1짜리 집 (-1,-2), (4,-2), (0,3) 이 서로 멀어 충전소 2개로는 못 덮으므로 `-1`.
