## 1. CNN의 한계

- CNN은 **시퀀스(순차) 데이터를 처리하기 힘들다**는 근본적인 한계가 있음
- 이 한계를 극복하기 위해 등장한 아이디어들이 **RNN**과 **어텐션 기반의 트랜스포머**

**CNN의 구체적인 한계**

1. **시퀀셜(순서) 데이터를 처리하기 부적합**
   - CNN은 순서가 중요한 데이터를 처리하는 데 적절하지 않음
   - 데이터의 순차적 순서 정보를 반영하기 어려움

2. **긴 거리 의존성(long-range dependency) 부족**
   - CNN은 **지역적(local) 특징 추출에는 강하지만**, 이미지나 문장에서 **멀리 떨어진 요소들 간의 관계는 잘 학습하지 못함**
   - 예시: 이미지 안에서 서로 멀리 떨어져 있지만 **반복되는 패턴**들이 있을 때, CNN은 이런 관계를 포착하기 어려움
   - CNN은 이미지 전체의 정보를 압축하는 데는 효과적이지만, 그 과정에서 **위치 정보가 손실**됨
   - 적절하게 가볍지만(효율적이지만), 픽셀 정보를 많이 버리기 때문에 **최고 성능을 내기는 어려움**

**정규화(Regularization) 관련 — CNN 복습**

- 합성곱(Convolution), 풀링(Pooling), 비선형 함수(활성화 함수), 완전연결(FC) 레이어로 구성됨
- **정규화(Normalization)**: 일반화 성능 개선을 위해, 데이터의 표준(스케일)을 맞춰주는 것
- CNN은 지금도 이미지 인식·탐지 분야에서 표준적으로 널리 활용되고 있음

## 2. RNN (Recurrent Neural Network) — 복습

- **순차적 데이터를 처리하기 위해 고안된 신경망 구조**
- **순차적 정보 반영**: 이전 단계의 데이터를, **은닉 상태(hidden state)**라는 형태로 다음 단계에 전달 → 시간/순서의 흐름을 반영할 수 있음
- **시계열/언어 데이터에 적합**: 문장, 음성 신호, 센서 데이터 등 시계열 데이터 처리에 관한 강력한 **귀납적 편향(inductive bias)**을 제공

### 예시 — 문장 생성

문자 시퀀스(예: "h", "e", "l", "l" → 다음 글자 예측)를 원-핫 인코딩으로 표현해서 RNN에 입력하는 예시:

**학습 단계**
- 입력 문자들이 각각 원-핫 벡터로 변환되어 순서대로 들어감
- 각 시점마다 히든 레이어(Whh 가중치로 이전 은닉상태 반영, Wxh로 현재 입력 반영)를 거쳐, 출력층(Why)에서 다음 글자에 대한 예측값이 나옴
- 이 예측값과 실제 정답 글자(Target)를 비교해서 학습

**실행(추론) 단계**
- 학습 때와 다른 점: 모델이 만들어낸 출력을, 다시 다음 시점의 입력으로 사용하면서 문장을 이어서 생성해나감 (자기회귀적, autoregressive)

> 즉 "이전 시점의 정보가 이후 시점에 영향을 주는" 구조 — 시계열 의존성이 존재함
>
> 순수 RNN은 (1) **이전 은닉 상태의 정보**와 (2) **현재 입력**, 이 두 가지를 반영해서 다음 은닉 상태를 계산함

### RNN의 한계 — 기울기 폭발/소실

- 시점(time step)이 많아지면, **기울기 폭발(exploding gradient)** 또는 **기울기 소실(vanishing gradient)**이 발생함
- 역전파 과정에서 시퀀스 데이터에 적용되는 연산은 본질적으로 **곱셈(같은 가중치 W를 반복해서 곱하는 형태)**으로 바뀜
  - 가중치 W의 특이값(singular value)이 1보다 **조금이라도 크면** → 여러 번 곱해지며 값이 기하급수적으로 커짐 → **기울기 폭발**
  - 가중치 W의 특이값이 1보다 **작으면** → 여러 번 곱해지며 값이 점점 작아져 결국 **0으로 수렴** → **기울기 소실**
- 실무적으로는 **기울기 폭발**을 특히 조심해야 함

**대응 방법 — 그래디언트 클리핑(Gradient Clipping)**

- 이상적으로는 W의 특이값이 1인 것처럼, 폭발할 것 같으면 **강제로 잘라내는(clip)** 방법을 사용
- 다만 이는 원래 데이터가 말해주는 방향과는 다른 "인위적인" 업데이트이기 때문에, 모델이 잘 학습되는 것을 오히려 방해할 수도 있음
- **기울기 소실**은 (클리핑처럼 단순하게) 풀기가 어려움 — 강제 절삭(클리핑)은 "폭발"에는 대응할 수 있지만, "소실"에는 근본적인 해결책이 되지 못함

## 3. LSTM — 복습과 한계

### 핵심 아이디어 복습

- **셀 상태(Cell State)**: 중요한 정보를 유지·기억하는 통로
- **게이트(Gate)**: 정보의 흐름을 제어 — 셀 상태를 얼마나 은닉 정보(히든 스테이트)에 반영할지를 결정
- **구동 철학**: 긴 시퀀스 데이터에서 **필요한 정보는 유지**하고, **불필요한 정보는 지워서** 안정적인 학습을 유도

**세 가지 게이트 (복습)**

| 게이트 | 역할 |
|--------|------|
| **입력 게이트(Input Gate)** | 새로운 정보를 셀 상태에 저장 |
| **망각 게이트(Forget Gate)** | 과거 정보를 셀 상태에서 제거 |
| **출력 게이트(Output Gate)** | 셀 상태를 현재 은닉 상태로 출력 |

### 왜 LSTM은 기울기 소실에 강한가

- 셀 상태를 업데이트할 때 쓰이는 **"+"(덧셈)** 연산이, 기울기 소실을 방지해주는 핵심 장치
- 각 시점에서의 기울기가, (RNN처럼 매번 곱셈만 반복하는 게 아니라) **덧셈 경로와 곱셈 경로로 분리**될 수 있음 → 덧셈 경로를 통해 기울기가 소실 없이 잘 전달됨
- (앞서 배운) **ResNet의 잔차 연결(Residual Connection)**과 유사한 원리 — 정보가 소실되기 쉬운 상황이 발생하더라도, 덧셈 경로 덕분에 기울기 소실을 상당 부분 막을 수 있음

### LSTM의 한계 — 정보 희석(Dilution) 문제

- 망각 게이트가 과거의 정보를 (한 번에 없애는 게 아니라) **조금씩 계속 줄여나감**
- 이 효과가 누적되면서, **과거의 중요했던 정보가 시간이 지날수록 점차 희석(약화)**됨
- 결정적 한계: 특정 타임스텝의 정보가 "지금 이 시점"에 얼마나 영향을 미치고 있는지를 **구체적으로 짚어내기 어려움** — "예전 시점의 정보다"라는 것만 어렴풋이 남아있을 뿐, "정확히 몇 시점 전의, 어떤 정보였는지"는 (모델 스스로도) 명확히 구분하지 못함

## 4. 어텐션(Attention) 메커니즘 — 이미지 관점에서 이해하기

### 이미지에서의 자기유사성(Self-similarity)

- 이미지 안에는, **픽셀 사이의 거리와 상관없이 서로 유사한 패치(patch)**들이 존재함 (패치 = 이미지를 일정한 크기로 잘라낸 작은 조각)
- 예: 이미지 노이즈 제거(denoising) 작업에서는, 흔히 **주변 픽셀들의 평균값**을 내는 방법을 사용하는데, 단순히 평균을 내면 이미지 해상도가 흐려짐(블러)
- 대신, **멀리 떨어져 있지만 비슷한(유사한) 픽셀·패치**를 찾아서 그 정보로 채워 넣으면, 해상도를 흐리지 않으면서도 노이즈를 제거할 수 있음
- 이미지 노이즈 제거를 예로 들었지만, 핵심은 **표현(representation)을 더 강건하게(robust) 만드는 것**이 중요하다는 점

**핵심 아이디어**: "관련성이 높은 패치(관련 정보)를, 최종 결정에 반영하자!"

### Query, Key, Value — 이미지 버전

| 요소 | 역할 |
|------|------|
| **쿼리(Query)** | 지금 집중하려는(주목하려는) 대상 |
| **키(Key)** | 비교 대상이 되는 다른 패치들 |
| **밸류(Value)** | 그 키(패치)가 담고 있는 실제 정보 |
| **어텐션(Attention)** | 쿼리와 키의 유사도를, 확률 분포 형태로 나타낸 것 (쿼리와 비슷한 키일수록 높은 값) |
| **출력(Output)** | 어텐션 가중치로 가감된 Value들의 총합 |

- 이 과정을 통해, "어떤 키(패치)가 쿼리와 비슷한지, 어떤 키가 쿼리와 다른지"를 알 수 있게 됨

**수식 정리**

```
q = xWq   (쿼리)
k = xWk   (키)
v = xWv   (밸류)

aᵢⱼ = softmax( qⱼ · kᵢ / √D )     ← 쿼리 j와 키 i 사이의 어텐션 가중치
yⱼ = Σᵢ aᵢⱼ · vᵢ                  ← 쿼리 j에 대한 최종 출력
```
(x: 입력, W: 각각의 가중치 행렬, D: 입력/특징 차원 수 — √D로 나누는 것은 이전에 배운 Scaled Dot-Product Attention과 같은 이유)

**이미지에서의 해석**

- 출력은 "어텐션으로 가감된 Value(패치 정보)들의 총합"
- 어텐션이 **높은 값을 가진 패치들끼리 묶으면**, 마치 **클러스터링(군집화)**을 하는 듯한 효과를 낼 수 있음
- 정답(레이블) 신호 없이도, 어떤 영역들이 서로 유사한지를 스스로 알아낼 수 있음
- 원래는 지도학습(supervision)이 필요할 것 같았던 문제인데, **셀프 어텐션만으로도** 이런 유사성을 잘 학습해낼 수 있다는 것이 밝혀짐

### 교차 어텐션(Cross-Attention)이란?

- **둘 이상의 서로 다른(이종) 데이터**로부터, 패치(요소) 간의 정보를 정의하는 방식
- 예: **텍스트-투-이미지(Text-to-Image) 모델**에서, 이미지와 텍스트 사이를 연결할 때 사용
  - **쿼리**: 이미지 패치
  - **키**: 텍스트(단어) — 텍스트 키가 담은 정보
- 이렇게 하면, **이종 데이터 간의 유사도**를 반영할 수 있음
- 전제 조건: 쿼리와 키를 서로 **비교할 수 있는(같은) 공간**이 필요함 (즉 이미지 패치와 텍스트가 같은 임베딩 공간에 있어야 서로 비교 가능)

> **어텐션의 강력함**: 지도학습 신호(레이블)가 전혀 없어도, 학습을 통해 "의미적으로 유사한 것이 무엇인지"를 스스로 학습해낼 수 있다는 것

## 6. ViT (Vision Transformer)

### 위치 인코딩 (Positional Encoding)

- 어텐션 자체에는 데이터의 순서(위치) 개념이 없기 때문에, ViT에서는 **각 입력 토큰(패치)에 위치 정보를 담은 벡터를 추가**해줌
- 방법은 여러 가지가 있음:

**① 학습 가능한(Learnable) 위치 인코딩**
- 데이터에 알맞게, 소량의 파라미터를 두고 위치 벡터 자체를 **학습**시키는 방법

**② 사인파(Sinusoidal) 인코딩** — 범용적으로 널리 쓰임
- 주기가 다른 여러 개의 사인파(sine wave)를 합성해서 위치를 인코딩 (시누소이달 모듈레이션)
- 고주파(high-frequency) 형태의 위치 인코딩 벡터를 사용하면 표현력이 좋아짐
- (x, y) 좌표를 그대로 벡터에 직접 사용하면, 저차원(값 하나짜리) 정보라서 표현력이 부족함
- 그래서 픽셀(위치) 자체에 **고주파의 사인 함수를 곱해줘서**, 그 고주파 성분 자체를 벡터 정보의 일부로 사용함

> `[개인 메모 · 시험범위 아님]` (필기자 본인의 이해) 주기가 다른 여러 사인파를 사용해서 마치 "시계"처럼 위치를 표현한다 — 각 사인파가 모두 다른 정보를 담고 있고, 위치는 달라도 (사인파 상에서) 거리가 같은 위상끼리는 계산하면 같은 값이 나오도록 인코딩됨. 시누소이달 인코딩을 쓰는 이유는, 처음 보는(학습 때 못 본) 위치가 나오더라도, 모델이 "이건 이런 위상이다"라는 걸 일반화해서 인식할 수 있도록 하기 위함으로 이해됨.

**③ 상대 위치 인코딩(Relative Positional Encoding)**
- 해상도가 달라져도 적용 가능하다는 장점
- 다만 절대적인 위치(예: 좌우 코너가 어디인지)를 고려하기는 어려움

**④ 회전 위치 임베딩 (RoPE, 2D 로터리 포지션 임베딩)**
- 위치 벡터를 (더하는 대신) **Q/K에 회전 행렬을 적용**하는 방식
- 상대 위치 표현이 가능하고, 해상도 가변에도 대응 가능
- 단점: Q/K를 계산할 때마다 매번 회전 연산이 추가로 필요(연산량 증가), 그리고 절대 위치 정보는 소실됨

### 인코더 내부 구조

**구성**: 정규화(Normalization) → 다중헤드 어텐션(Multi-Head Attention) → 정규화(Normalization) → 연결층(FFN)

| 구성요소 | 역할 |
|-----------|------|
| **정규화(Normalization)** | 입력값을 균일한 스케일로 맞춰줌 |
| **다중헤드 어텐션** | 여러 관점에서 패치 간의 관계를 학습 (어떤 헤드는 "형태", 어떤 헤드는 "색", 또 다른 헤드는 "위치" 등 서로 다른 것에 주목) |
| **연결층(FFN, MLP)** | 어텐션이 뽑아낸 정보를 조합·변환해서, 더 풍부한 특징을 생성 |

- 이런 인코더 블록을 **L개** 통과시킴 (일반적으로 12개 이상)

### ViT의 전역(Global) 관계 학습

- **CNN**: 지역적인 영역에서 시작해서, 레이어를 쌓아가며 점진적으로 수용영역을 넓혀서 전역을 이해 (간접적, 점진적)
- **ViT**: 셀프 어텐션을 통해, **처음부터 전역(모든 패치 간의) 관계를 한 번에 학습**할 수 있음 (직접적)

- 마지막에는 **MLP 헤드**가 최종 예측(분류 등)을 수행

## 7. ViT vs CNN — 성능 비교

- (이미지넷 기준) ViT는 **ResNet보다 성능이 우수**한 것으로 나타남
- 다만, ViT는 **훨씬 많은 데이터로 사전학습**을 했을 때 그런 결과가 나온 것이라, 단순 비교에 유의가 필요함

**핵심 차이 — 데이터 양에 따른 성능 변화**

| 모델 | 데이터가 많아질수록 성능은? |
|------|-------------------------------|
| **ViT** | 데이터를 많이 받을수록 **성능이 계속 오름** |
| **ResNet(CNN)** | 데이터를 많이 받아도, 그에 비례해서 성능이 오르지는 않음 (어느 순간 정체) |

- 즉 **ViT는 거대한 데이터셋으로 사전학습할 때 특히 우수**함

**ViT 학습 시 중요한 것 — 정규화와 데이터 증강**

- ViT는 막대한 수의 파라미터(모델 상수)를 보유하기 때문에, **정규화(Normalization) 기법**과 **데이터 증강(Data Augmentation) 기술**이 매우 중요함
- 데이터 증강 예시: 이미지를 지터리(jittery)하게 무작위로 자르기, 색깔 변형, 이미지 흔들기(회전/이동 등) — 표준적으로 쓰이는 증강 기법들이 다양하게 존재
- **ResNet(CNN)**: 데이터 증강을 하면 성능에 도움이 됨
- **트랜스포머(ViT) 계열 모델**: 정규화와 데이터 증강을 함께 적용했을 때 특히 더 좋은 성능을 보임

### ViT의 효과적인 학습 전략 — 증류학습 (Knowledge Distillation)

- **증류학습(Distillation)** 기술이 ViT 학습에 효과적임
- **선생님(Teacher) 모델**: 이미지 레이블을 활용해 학습된, 훨씬 크고 강력한 모델 — 보통 **CNN 모델**을 선생님으로 씀 (CNN이 이미지에 특화되어 있기 때문)
- **학생(Student) 모델**: 선생님 모델의 예측을 따라가도록(모방하도록) 학습되는, 상대적으로 작은 ViT 모델

**손실 함수 구성**

- 선생님 모델의 예측값을 "수도 레이블(pseudo-label)"로 사용

> `[개인 메모 · 시험범위 아님]` (원문 삽입 설명) 여기서 "예측값"이란, 소프트맥스를 거치지 않은/조작하지 않은 마지막 출력(로짓, logit)을 의미함

- 이 값을 이용해, **KL 발산(KL Divergence) 손실** (선생님의 진짜 출력 분포를 닮아가도록 하는 손실)과 **교차 엔트로피(Cross-Entropy) 손실**을 **둘 다 함께** 사용
- 학생 ViT 모델은, 별도의 **학습 가능한 토큰(distillation token)**을 추가로 입력받아서, 이 토큰이 선생님 CNN 모델의 로짓(logit)을 학습하도록 설계됨

> **증류학습은 ViT 성능에 상당한 개선 효과**를 줌

## 8. 비전 트랜스포머의 트렌드 — 다양한 변종

- ViT에도 다양한 변종(variant)들이 존재
- 질문: "CNN처럼, 이미지의 계층적(hierarchical) 구조를 활용할 수는 없을까?"

### Swin Transformer

- 이미지 **전역(모든 패치)에 대해 직접 어텐션을 수행하는 것은 계산 비용이 매우 커서 비효율적**
- 개념적으로는, (CNN처럼) **레이어를 여러 겹 쌓으면 수용영역이 넓어진다**는 원리를 활용

**Swin Transformer의 아이디어**

- 이미지를 여러 개의 **윈도우(window) 영역**으로 나누고, 그 **윈도우 내부에서만** 어텐션을 수행 (계산량 절감)
- 그다음 레이어에서는, 윈도우의 위치를 **한 칸씩 옮겨서(shifted window)** 다시 어텐션을 수행
- 이렇게 윈도우 1과 윈도우 2가 서로 겹치면서(중첩되면서), 최종적으로는 **이미지 전역을 고려하는 효과**를 냄 (CNN의 "레이어를 쌓을수록 수용영역이 넓어지는 것"과 비슷한 원리를, 트랜스포머 구조 안에서 구현한 것)

## 9. 최신 SOTA(State-of-the-Art) 비전 모델 개관

**왜 트랜스포머에 이렇게 많은 시간을 투자했는가?** → 현재 최고 수준(SOTA)의 구조들을 이해하기 위해서

| 모델 | 유형/개발사 | 특징 |
|------|--------------|------|
| **ViT-22B** | 비전 백본, Google Research | **지도학습** 채택, 대규모 비공개 레이블 데이터로 학습. 압도적인 일반화 성능을 보이지만, 데이터가 공개되지 않아 (외부에서) 재현이 불가능함 |
| **DINOv3** | 자기지도 비전 백본, Meta AI | 라벨 없는 대규모 데이터(LVD-1.7B, 약 17억 장)로 학습. **자기지도학습**(대조학습/증류/보간 기법 활용). 가중치가 공개되어 있고, 현존 최고 수준의 조밀한(dense) 특징 맵을 제공 |
| **SigLIP2** | 비전-언어 모델, Google Research 멀티모달팀 | (CLIP 계열) **지도학습** 채택. **시그모이드 기반 손실** 및 LLM 기반 임베딩 정렬 채택. 회전 위치 인코딩 및 가변 해상도 처리 지원, 모델 가중치 공개. 긴 텍스트·다국어·고해상도 환경에서 우수한 성능 |
| **Qwen-VL, LLaVA-NeXT** | 멀티모달 비전 백본 | 비전 인코더와 LLM을 **초반부터 통합해서 학습**하는 아키텍처 채택 — 이미 따로 학습된 인코더와 디코더를 나중에 정렬(align)하는 방식이 아니라, **처음부터 둘을 함께 학습**시킴 |

**앞으로의 경쟁 구도**

- "따로 학습된 최고 수준(SOTA)의 인코더 + 최고 수준의 디코더를, 나중에 정렬(align)해서 결합하는 방식"과, "처음부터 통합해서 함께 학습하는 방식" — 이 두 가지 방식이 앞으로 계속 경쟁할 것으로 예상됨. 둘 중 어느 한쪽이 완전히 배제되기는 어려울 것

## 10. ViT 장단점 정리

| 구분 | 내용 |
|------|------|
| **장점** | **전역 문맥을 한 번에 고려 가능**. 시계열/시퀀스 데이터의 경우, (위치 인코딩을 통해) 순서 고려 가능 — 순서가 없는 데이터의 경우 위치 인코딩을 선별적으로 제거하는 것도 가능 |
| **단점** | 대규모 학습 자원 필요 (대규모 데이터 및 GPU 자원 — 특히 메모리 — 요구). **학습 데이터 규모가 작을 경우, CNN보다 성능이 떨어짐**. 한 번에 고려할 수 있는 토큰(패치) 수가 제한적 |
| **활용** | 이미지 분류/탐지/분할/생성에서 모두 SOTA 성능 달성. **멀티모달 모델에서 기준(baseline) 아키텍처**로 널리 활용. 현재도 기준 모델로 활용되는 중 |
