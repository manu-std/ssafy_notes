## 2. 파운데이션 모델이란

- 대량의 데이터를 기반으로 사전 학습된 대규모 AI 모델

## 3. 트랜스포머·어텐션 기반 모델 이해 점검

> `[개인 메모 · 시험범위 아님]` 개인적인 이해를 정리하면: 트랜스포머와 어텐션으로 만들어진 모델은 기본적으로 입력을 인코더를 통해 텐서 공간에서 의미를 가진 벡터로 뿌리고, 이 벡터는 의미를 가진다. 그리고 의미를 가진 벡터를 디코더를 통해, 코사인 유사도가 유사한 벡터를 찾아 의미를 가진 데이터를 출력으로 낸다 — 이 이해가 정확한지 평가하고 보충 설명을 붙여줄 것

**답변** `[개인 메모 · 시험범위 아님]`

이 이해는 큰 그림에서는 맞는 방향을 잡고 있지만, 세부적으로 정정하고 보충할 부분이 몇 가지 있다.

**① 맞게 이해한 부분 — "입력이 의미를 가진 벡터가 된다"**

트랜스포머 기반 모델은 입력 토큰(단어/부분단어)을 임베딩(embedding)한 뒤, 셀프 어텐션(self-attention) 층을 여러 겹 통과시키면서, 각 토큰이 "문맥 속에서 어떤 의미를 갖는지"를 반영한 벡터로 계속 다듬어간다. 그래서 "입력이 고차원 벡터 공간(텐서 공간)에서 의미를 가진 벡터로 뿌려진다"는 표현은 방향성 자체는 정확하다.

**② 정정이 필요한 부분 — "인코더를 통해서"라는 표현**

이 강의 뒷부분(6장)에서 다루듯, GPT(지피티1)는 트랜스포머의 **디코더** 구조만 사용하고, BERT는 트랜스포머의 **인코더** 구조만 사용한다. 즉 인코더와 디코더를 둘 다 갖춘 구조는 번역 모델이나 T5처럼 특정 목적을 가진 일부 모델에만 해당하고, 우리가 흔히 쓰는 챗GPT·클로드 같은 대화형 LLM은 **디코더만으로 이루어진 구조**다.

그러니 "입력을 인코더에 통과시켜서 의미 벡터를 얻는다"는 설명은, 번역기 같은 인코더-디코더 구조에는 맞는 말이지만, 우리가 주로 다루는 GPT류 LLM에는 정확히 들어맞지 않는다. GPT류 모델에서는 별도의 인코더 없이, 여러 겹 쌓인 디코더 블록이 입력을 읽어 의미 있는 벡터로 만드는 일과 다음 단어를 예측하는 일을 모두 담당한다.

**③ 흥미로운 부분 — "코사인 유사도로 유사한 벡터를 찾아 출력을 낸다"**

이 직관은 사실 상당히 정확하다. 디코더를 통과해 나온 마지막 벡터(은닉 상태, hidden state)는, 실제로 모델이 알고 있는 모든 단어(어휘, vocabulary) 각각의 임베딩 벡터와 내적(dot product)을 계산한다 — 벡터 크기를 정규화하면 이 내적은 코사인 유사도와 사실상 같은 역할을 한다. 이렇게 계산된 값(로짓, logit)에 소프트맥스를 씌우면 "다음에 올 단어일 확률" 분포가 나온다. 그러니 "의미가 비슷한 벡터를 찾아서 출력을 낸다"는 표현은, 이 마지막 단계를 상당히 정확하게 짚어낸 직관이다.

다만 이 단계는 "디코더"라는 큰 블록 전체가 아니라, 디코더를 다 통과하고 난 뒤에 붙는 **별도의 출력층(LM Head)**에서 일어나는 계산이라는 점만 구분해주면 된다.

- 디코더: 문맥을 이해하고, 각 토큰의 벡터를 다듬는 부분
- 출력층(LM Head): 그 벡터로 "다음 단어일 확률"을 계산하는 부분

참고로 이렇게 나온 확률 분포에서 실제로 어떤 단어를 최종적으로 고를지(그리디하게 가장 확률 높은 것을 고를지, 확률적으로 샘플링할지 등)는, 아래 5장에서도 언급하듯 3차시 "디코딩"에서 더 자세히 다룰 예정이다.

> 정리: 전체 흐름("입력 → 의미 있는 벡터 → 유사도 기반으로 출력")을 짚은 감각은 훌륭하다. 다만 (1) 우리가 주로 다루는 LLM은 인코더가 아니라 디코더만 쓴다는 점, (2) "유사도로 출력을 고른다"는 부분은 디코더 블록 자체가 아니라 그 뒤에 붙는 별도의 출력층(LM Head)에서 일어나는 계산이라는 점, 이 두 가지만 구분하면 완벽하다.

## 4. 파운데이션 모델 이전 vs 이후 — 패러다임 변화

- 파운데이션 모델 이전에는 **태스크마다 별도의 학습**이 필요했음
- 원래는 사람이 직접 피처(feature)를 추출해서 모델에 줘야 했음
- 딥러닝 시대가 오면서, 피처 추출도 AI가 직접 하도록 맡기게 됨
- 더 나아가 **사전 학습(pre-training) 단계**를 추가하고, 필요한 태스크에 맞춰 **파인튜닝(fine-tuning)**하는 방식이 자리잡음
- 시대가 지날수록 점점 덜 번거로워졌지만, 그래도 매번 어느 정도의 학습은 필요했음
- **지금은 새로운 태스크를 풀고 싶을 때, 자세한 설명(프롬프트)을 입력해주는 것만으로 충분해짐**

| 예시 | 예전 방식 | 지금 방식 |
|---|---|---|
| 삼행시 잘하는 AI 만들기 | 삼행시 데이터를 대량으로 수집 → 연산량도 많아 비용이 큼 | 그냥 설명(프롬프트)만으로 기대한 결과를 얻음 |
| 영상 생성(Sora 등) | 태스크 전용 데이터·학습 필요 | 자세한 프롬프트 입력만으로 원하는 영상 생성 |

## 5. 파운데이션 모델의 3가지 구성 요소

### ① 빅데이터

- "AI 시대"라고 부르지만, 사실 그 이전엔 "빅데이터 시대"가 먼저 있었음
- 인터넷을 통해 가상의 데이터, 즉 빅데이터를 공유할 수 있게 됨
- **2025년 기준 약 175ZB(제타바이트)**의 데이터가 쌓여 있음
- 딥러닝 연구자들은 **데이터가 많아질수록 성능도 높아지는 경향**을 발견함

### ② 자기지도학습 (Self-Supervised Learning)

- 기존 학습 알고리즘은 피처(feature)와 라벨(label) 쌍이 필요했음
- 연구자들은 "라벨링 없이, 데이터 자체만으로 학습할 방법이 없을까"를 고민
- 이를 대표적으로 해결한 알고리즘이 **자기지도학습(Self-Supervised Learning)** — 데이터 자체에서 학습 시그널을 뽑아냄
- 텍스트 모델에서는 **다음 토큰 예측(Next Token Prediction)**을 학습 시그널로 사용

**예시**: 인터넷에서 "아까 밥 먹고 왔어"라는 문장을 추출했다면

| 구분 | 내용 |
|---|---|
| 학습 데이터(입력) | "아까 밥 먹고" |
| 라벨(정답) | "왔어" |

모델은 "아까 밥 먹고"라는 입력을 받았을 때 "왔어"를 맞혀야 하고, **크로스 엔트로피(Cross Entropy)** 손실로 학습함

> **자주 나올 법한 질문**: "왔어"도 맞고, "왔는데"도 맞고, "왔거든"도 맞는 말인데, "왔어"만 확률을 높여주는 게 타당한가?
>
> 문장 하나만 놓고 보면 이상해 보일 수 있지만, 이런 학습을 **1조 개**의 문장에 대해 반복하면, 모델은 결국 사람들이 보편적으로 할 법한 다양한 말을 두루 배우게 된다. 학습이 끝나면 모델은 인터넷상의 사람들이 실제로 할 법한 말을 하게 됨.

- 비전 파운데이션 모델(추후 차시에서 다룰 예정)의 **디퓨전 모델**도, "노이즈에서 이미지를 복원"하는 방식의 자기지도학습의 한 종류
- 다음 토큰을 실제로 어떻게 고르는지(디코딩)는 **3차시**에서 다룰 예정

### ③ 어텐션과 트랜스포머

- **어텐션(Attention)**: 입력 데이터에서 중요하다고 생각되는 부분에 모델이 스스로 주의를 집중하게 만드는 메커니즘
- **트랜스포머(Transformer)**: 어텐션을 기반으로 하는 신경망 구조
- 방대한 데이터를 자기지도학습으로 배우려면, 그만큼 학습을 잘 소화할 수 있는 모델 구조가 필요함 — 아무리 많고 좋은 데이터가 있어도 모델 구조가 적절하지 않으면 제대로 학습되지 않음
- CNN을 포함해 다양한 모델 구조가 있었지만, 연구자들은 **어텐션과 트랜스포머 구조가 방대한 데이터를 소화하는 데 특히 유리하다**는 것을 경험적으로 발견함

> 정리하면, **많은 데이터 + 자기지도학습 알고리즘 + 어텐션·트랜스포머 구조**가 파운데이션 모델의 기본 골격이라고 해도 과언이 아니다.

## 6. GPT vs BERT — 같은 3요소인데 왜 능력 차이가 날까

BERT 모델도 이미 위 3가지 구성 요소(빅데이터, 자기지도학습, 트랜스포머)를 모두 포함하고 있는데, 왜 지금 우리가 기대하는 "파운데이션 모델급" 능력을 보여주지 못했을까? BERT는 이전의 SOTA(최고 성능) 모델들을 다 앞질렀지만, 그런 퍼포먼스는 보여주지 못함 — 디코더만 써서 그런 걸까?

| 모델 | 구조 | 특징 |
|---|---|---|
| **GPT-1** (BERT와 비슷한 시기 등장) | 트랜스포머 **디코더** 구조 | 앞의 단어는 뒤의 단어를 볼 수 없음 (단방향) |
| **BERT** | 트랜스포머 **인코더** 구조 | 양방향(bi-directional) 구조 — 한 단어가 앞뒤 단어를 모두 참고할 수 있음 |

- **GPT-2**: GPT-1 구조에서 파라미터와 데이터를 각각 10배씩 늘림
  - GPT 모델이 갑자기, 추가 학습 없이도 **텍스트 지시만으로 새로운 태스크를 어느 정도 수행**할 수 있는 능력을 보여줌 (아주 잘한 건 아니지만 어느 정도는 해냄)
  - GPT-2조차도 **언더피팅(underfitting)**이 발생 — 모델 크기를 더 키우면 성능이 더 개선될 여지가 있었다는 뜻. 대용량 데이터를 소화하기엔 GPT-2조차 사이즈가 작았음

> ⚠️ **어려운 점**: 트랜스포머 모델은 파라미터 수에 정비례해서 연산량이 늘어나는 게 아니라, **제곱(quadratic)에 가깝게** 늘어남 — 파라미터를 10배 늘리면 비용은 대략 100배가 든다는 이야기

## 7. 스케일링 법칙 (Scaling Law)

- **카플란(Kaplan)**이라는 연구자가, 직접 큰 모델로 실험해보지 않고도 **스케일링 로우(Scaling Law)**라는 법칙을 발견
- 직접 큰 규모로 실험하기엔 비용이 너무 크기 때문에, 작은 규모의 실험들로 추세선을 그림
- 연산량, 데이터 크기, 파라미터 수에 대한 추세선이 실제로 잘 들어맞았음
- 결과적으로, **모델을 실제로 학습시키기 전에도 성능을 어느 정도 예측**할 수 있게 됨

> 📌 재밌는 부분: 이 법칙을 발견한 연구자가 오픈AI를 그만두고 창업한 회사가 **앤트로픽(Anthropic)**이다.

- 추세선이 높은 확률로 잘 맞아서, "100배를 더 쓰면 4배 정도 성능을 올릴 수 있겠다" 같은 예측을 할 수 있게 됨
- 다만 중요한 한계: 스케일링 법칙은 어디까지나 "다음 단어 예측을 얼마나 더 잘할까"에 대한 법칙이지, "이걸 잘하면 실제로 얼마나 돈을 벌 수 있는가"는 별개의, 모호할 수 있는 문제

## 8. 창발성 (Emergence)

- 특정 규모(scale)를 넘어서면 **창발성(Emergence)**이 나타남
- 창발성: 주어진 설명과 예시만으로 새로운 태스크를 수월하게 수행하는 능력이 발현되는 현상
- 예: **퓨샷(Few-shot)으로 번역하기**
  - 예전: 영어→한국어 번역을 하려면, 영어-한국어 쌍 데이터를 만들어 파인튜닝을 해야 했음
  - 지금: 퓨샷(예시 몇 개)만으로 처리 가능해짐

**모델 크기에 따른 퓨샷 번역 성능 변화**

| 모델 크기 | 퓨샷 번역 성능 |
|---|---|
| 1.3B | 퓨샷을 아무리 시도해도 잘 안 됨 |
| 13B | 조금 됨 |
| 175B | 성능 곡선의 기울기가 갑자기 가팔라짐 — 이것이 창발성 |

- 추론 능력(reasoning)도 창발성의 대표적인 예시 중 하나
- 텍스트 파운데이션 모델의 대략적인 기준: 기존 대비 더 큰 모델(대략 **7B 이상**)이 **1T(1조) 개 이상**의 데이터로 학습되면서 창발성이 나타나기 시작함
- 다만 시간이 지나며 기준 자체가 계속 바뀌고 있어서, 절대적인 기준은 아님

## 9. 폐쇄형 모델 vs 개방형 모델

| 구분 | 폐쇄형 (Closed) | 개방형 (Open) |
|---|---|---|
| 대표 모델 | GPT, Claude, Gemini | LLaMA, DeepSeek, Mistral |
| 접근 방식 | 앱/웹 또는 API 콜을 통해 호출 | 무료로 다운로드 가능 |
| 공개 정보 | 모델 구조 접근 불가 — 출력이 어떻게 만들어지는지 알 수 없음 (블랙박스) | 모델 구조, 소스 코드, 가중치 등 모든 정보 공개 |
| 성능/최신성 | 일반적으로 더 우수한 성능과 최신 기능, 사용하기 쉬움 | 폐쇄형 대비 성능이 낮은 편 |
| 비용/자원 | 사용량마다 비용 발생, 모델 출력·정보가 제한적 | GPU 등 자체 인프라 필요 |

> 폐쇄형이 "문제"라는 뜻은 아니지만, 디버깅 관점에서는 블랙박스라는 한계가 있음. 반대로 개방형 모델은 — 사람이 뇌에 문제가 생기면 뇌를 열어볼 수 있듯 — 어떤 가중치가 문제인지 직접 들여다볼 수 있다는 장점이 있음
