## 🧮 0. 계산 문제 총정리

각 세트의 **마지막 문항(14번)은 거의 항상 계산 문제**였다. 유형이 정해져 있으니 공식만 확실히.

### ⭐ Precision / Recall / Accuracy / F1

혼동행렬(TP=30, FP=20, FN=10, TN=40):

```
Precision = TP / (TP + FP)   ← "내가 양성이라 한 것 중 진짜 양성"   = 30/50 = 0.60
Recall    = TP / (TP + FN)   ← "실제 양성 중 내가 잡아낸 비율"     = 30/40 = 0.75
Accuracy  = (TP+TN) / 전체                                     = 70/100 = 0.70
F1        = 2 × (P×R) / (P+R)   ← 조화평균                       ≈ 0.67
```

- **핵심은 분모**: Precision 분모 = 예측한 양성(TP+FP), Recall 분모 = 실제 양성(TP+FN).
- 외우는 법: **P는 예측(Prediction)이 분모, R은 실제(Real)가 분모.**
- 함정: Accuracy(0.70)를 정밀도·재현율로 착각하는 ④번 선지.
- 비용: 스팸 필터는 **FP가 치명적**(정상 메일 누락) → Precision 중시 / 병원 진단·화재 감지는 **FN이 치명적** → Recall 중시.

### 공식 모음

## 🔴 1. 실제로 틀렸던 개념

### [04] 참 함수 f* vs 측정오차 ε
- **오류(Error) ≠ 측정오차(ε)** — 오류(ŷ−y)는 학습으로 줄일 대상, ε(irreducible error)는 **절대 못 줄임**.
- f*는 직접 관측 불가능한 "실제 평균 관계", **데이터 = f* + ε**. ε는 X와 독립이고 E[ε] = 0.

### [05] 회귀 결과표 — t값과 p-value
- **t-statistic이 커질수록 p-value는 작아진다**(반비례). t = 계수 ÷ 표준오차.
- 유의성은 **반드시 p-value**로 판단(p < 0.05). 계수 크기는 **단위 문제**라 크기만으로 강약을 말할 수 없다.

### [05] 다중선형회귀 — 유의하지 않은 계수의 부호
- **p > 0.05인 계수는 부호를 읽지 않는다.** 계수가 음수여도 "0과 다르다"는 근거가 없다.
- 계수 해석 = 다른 변수 고정 시 xⱼ 1단위↑ → y 평균 변화량(편미분).
- 광고 데이터: TV·radio는 p < 0.0001로 유의, **newspaper는 p = 0.8599로 무의미**. R²는 0.612(단순) → **0.897(다중)**.

### [06] Word2Vec — Skip-gram vs CBOW
- **CBOW가 빠르고 빈도 단어에 강함 / Skip-gram은 느린 대신 희귀 단어·구 표현에 강함.**
- SG = 중심 단어로 주변 예측, CBOW = 주변 단어로 중심 예측.

### [06] LSTM 포겟 게이트
- 게이트 값은 **매 시점 xₜ, hₜ₋₁로 동적으로 재계산**. 학습 후 고정되는 상수가 아니다.
- fₜ = σ(Wf·[hₜ₋₁, xₜ] + bf), 이후 **fₜ × Cₜ₋₁**로 곱해져 살아남는 비율이 결정된다.

### [07] Self-Attention의 한계 — RNN 한계와 혼동 주의
- 한계는 딱 3가지: **① 순서 정보 부재 → Positional Encoding, ② 비선형성 부족 → FFN, ③ 미래 참조 → Masked Self-Attention.**
- **"병렬화 불가"는 RNN의 한계.** 멀티헤드도 병렬화 장치가 아니라 **여러 관점**을 위한 것.

### [09] 지시 학습(Instruction Tuning) 등장 배경
- 해결책은 **모든 태스크를 자연어 지시 형태로 통일**해 출력도 자연어로.
- "태스크마다 별도 출력층(head)"은 **기존 프레임워크 방식**(정반대). 기존 방식 비용 = n종류 데이터 + n번 학습 + n개 모델.

### [12] ViT 증류학습(Knowledge Distillation)
- 학생 ViT는 **별도의 distillation token**을 추가로 두고, 그 토큰이 **선생님(CNN)의 로짓**을 학습.
- 손실 = **KL 발산 + 교차 엔트로피 둘 다**. 선생님의 예측 = 수도 레이블.

### [14] Text-to-3D에서의 CLIP loss 활용
- **CLIP 인코더는 고정(freeze)**, 역전파로 바뀌는 건 **이미지/3D 파라미터**.
- CLIP을 "감정사"로 고정하고 점수가 높아지도록 대상을 고쳐나감. 3D는 **미분 가능한 렌더링** 필요. 단일 데이터에 대한 학습이므로 사실상 **최적화**.

### [14] CLIP·SigLIP·LLaVA·Qwen-VL 종합 ⚠️ (합답형)

| 모델 | 반드시 기억할 사실 |
|---|---|
| **CLIP** | **4억 쌍** 이미지-텍스트, HTML **alt 태그** 수집 |
| **SigLIP** | 쌍마다 **독립적인 이진 분류(시그모이드)** |
| **LLaVA** | 사전학습 = **선형층만** / 파인튜닝 = **언어모델도 함께**(FP16 양자화) |
| **Qwen-VL** | **Stage 1 저화질 → Stage 2 고화질** |

- 틀린 지점: "LLaVA는 언어모델을 끝까지 고정한다" → **단계에 따라 다르다.**

## ⛔ 2. 아예 못 풀었던 문제 (여기가 제일 위험)

### [04-8] 정밀도 / 재현율 계산 → 0번 섹션 참조

### [05-12] 역전파
- **연쇄법칙**: 출력 오차 기준으로 그래프를 **역으로** 따라가며 미분. 바깥 변화율 × 안쪽 변화율.
- **"역"전파인 이유**: 뒤쪽 레이어의 미분값을 **재사용**해서 효율적.
- ⭐ 함정: **"은닉층이 많을수록 항상 이득"은 틀림.** 깊어지면 표현력↑, 학습은 어려워짐(**기울기 소실**) → **No Free Lunch**.

### [06-14] 컨텍스트 벡터 계산
- 정답 = **Σ αⱼ·vⱼ**. 함정 = 단순 합(v₁+v₂+v₃), 가중치 자체.
- 가중치 합이 1인 이유는 2단계 **Softmax**를 통과했기 때문.

### [09-2 / 09-14] GPT-3 헤드 계산 (2문항 연속 실점)
- d_head = 12288 ÷ 96 = **128** / n_heads = 4096 ÷ 128 = **32**
- ⭐ 함정: 헤드 **개수**와 헤드 하나의 **차원**을 바꿔 쓰기.

### [14-11] Qwen-VL의 RoPE
- RoPE는 **더하는** 게 아니라 **Q/K에 위치 인덱스만큼 회전(rotation)**.
- 기존 PE(사인파·학습형)가 **+PE로 더하는** 방식. **멀티모달 RoPE**는 2D(이미지)·3D(비디오) 인덱스까지 인코딩.

### [14-12] VLA(Vision-Language-Action)
- **입력** = 텍스트 명령 + 로봇 시점 영상, **출력** = **행동(위상 변화·관절 움직임)**. 캡션 아님. **피지컬 AI**.

## 🟡 3. 맞았지만 불확실 표시했던 개념

- **[05] 로지스틱 회귀**: 로그 오즈 = 가중치×x + 편향 → **로짓 변환하면 다시 선형회귀 형태**. 오즈 = 성공/실패 확률(몇 **배**), 로짓 = log(오즈). 모형 = **선형식 + 시그모이드**.
- **[05] 로지스틱 계수 해석**: 계수 = **로짓 증가량**(확률 증가량 아님, 비선형). 오즈는 **exp(계수)배**. 작아도 유의하면 무관하지 않다 — balance 1000→2000에서 확률 0.006 → 0.586(약 97배).
- **[06] RNN 파라미터 공유 / 4-gram**: 모든 시점이 동일 가중치(Whh, Wxh) 공유. 4-gram은 직전 3개(N−1개)만 문맥.
- **[06] 어텐션 가중합**: 정답은 **Σ αⱼ·vⱼ**.
- **[07] Softmax는 자기 자신 포함**해서 계산.
- **[07] MLM 손실**: 이진 분류가 아니라 **전체 vocab 교차 엔트로피**.
- **[07] 디코더 구조**: 첫 어텐션(마스크드)은 자기 이전 출력만. 인코더 참조는 그다음 인코더-디코더 어텐션.
- **[07] GPT-1/BERT**: 둘 다 이미 3요소(빅데이터·자기지도학습·트랜스포머)를 포함.
- **[09] RLHF Step 2**: 사람 레이블과 모델 점수가 **같은 순서로 정렬되도록 손실 설계**한다는 건 **맞는 설명**. 틀린 선지는 "끝까지 돌려도 발산 위험 없다" — 실제로는 **사람이 중간중간 점검**한다.
- **[12] 교차 어텐션**: 이종 데이터도 **같은 임베딩 공간**이어야 유사도 계산 가능.
- **[12] ViT 전역 관계**: 셀프 어텐션으로 **처음부터 전역을 한 번에**(CNN은 쌓아야 도달).
- **[13] ResNet 두 번째 conv 0 초기화**: 무력화가 아니라 **스킵 커넥션에만 의존**(입력=출력)시켜 안전 출발.
- **[13] 배치 사이즈**: **작으면 정규화 효과, 크면 안정성.**
- **[13] 얼리 스타핑**: **검증 손실** 기준.
- **[13] 초기 손실값**: log(클래스 개수). 0에 가까우면 **라벨 누수 신호**.
- **[15] Marigold**: **합성 데이터** 파인튜닝, **2.5D**(3D 아님), 단안 깊이 추정.

## ⚔️ 4. "정반대로 외우기 쉬운" 쌍 — 시험장에서 헷갈리면 여기만

오답의 절반 이상이 **A와 B가 뒤바뀐 선지** 유형이었다.

| 개념 | 이쪽이 맞다 | 반대로 쓰면 오답 |
|---|---|---|
| Skip-gram vs CBOW | **CBOW = 빠름 / SG = 느림·희귀단어** | SG가 빠르다 |
| 오류 vs 측정오차 ε | **ε는 절대 못 줄임** | ε를 학습으로 줄인다 |
| t값 vs p-value | **t↑ ⇒ p↓** | 비례한다 |
| MSE vs R² | **구체적 오차 크기 = MSE** | R²로 오차 크기를 안다 |
| 오버피팅 vs 분포 변화 | **둘은 별개**(과적합 없어도 발생) | 같은 현상 |
| LOOCV vs K-fold | **LOOCV가 계산 비용 큼**(잘 안 씀) | LOOCV가 가볍다 |
| Self-Attention 한계 | 순서·비선형성·미래참조 | **"병렬화 불가"(← RNN)** |
| 마스킹 값 | **−∞** (exp(−∞)=0) | 0 (exp(0)=1이라 안 죽음) |
| 멀티헤드 차원 | **d_model을 쪼개서 나눠 가짐** | 헤드마다 전체 차원 사용 |
| 지시 학습 | 자연어 지시로 **통일** | 태스크마다 head 추가 |
| 모델 크기와 지시학습 | **8B 이하는 오히려 하락**, 70B↑ 개선 | 작아도 항상 이득 |
| Xavier vs He | **ReLU면 He**(√(2/dim)) | ReLU에 Xavier |
| L1 vs L2 | **L1=0으로 만듦(희소) / L2=큰 값 억제** | 뒤바꿈 |
| 드롭아웃 | **테스트 시 전부 사용** + 스케일링 | 테스트 때 끈다고 착각 |
| 파라미터 집중 | **FC=파라미터 / Conv=연산량 / 초기층=메모리** | 뒤바꿈 |
| ViT 증류 | **distillation token 별도** | 클래스 토큰만 사용 |
| ViT vs CNN 데이터량 | **ViT는 계속 상승 / CNN은 정체** | 반대 |
| Swin | 윈도우 내부만 → **shifted로 전역 효과** | 전역에 직접 어텐션 |
| 제로샷 vs 퓨샷 | **제로샷=배경지식만 / 퓨샷=예시 몇 개** | 뒤바꿈 |
| CLIP loss(Text-to-3D) | **CLIP 고정, 이미지/3D 업데이트** | CLIP을 학습 |
| LLaVA 학습 | 사전학습=선형층 / **파인튜닝=LM도** | LM 끝까지 고정 |
| RoPE vs 기존 PE | **RoPE=회전 / 기존=덧셈** | RoPE도 더한다 |
| 소프트 라벨 | **Softmax 통과 전 = 로짓** | Softmax 통과 후 확률 |
| LDM | **효율 + 품질 둘 다 향상** | 품질을 희생 |
| ResNet 2nd conv=0 | **스킵에만 의존시키려고** | 스킵을 무력화 |
| 얼리 스타핑 | **검증 손실** 기준 | 훈련 손실 |
| 깊은 신경망 | 깊을수록 **학습은 어려워짐** | 항상 이득 |
| 파라미터↔연산량 | **제곱 비례** | 정비례 |
| 로지스틱 계수 | **로짓 증가량 / 오즈는 exp배** | 확률 증가량 |
| 폐쇄형 vs 개방형 | **가중치 공개 = 개방형** | 폐쇄형이 공개 |

## 📚 5. 전범위 핵심 개념 압축 정리

> 오답 여부와 무관하게 **출제된 개념 전체**를 세트별로 압축했다. 만점 세트도 여기 포함되어 있으니 훑고 갈 것.

### [03] 데이터 전처리
- **분석 순서**: 데이터 불러오기 → **EDA** → **전처리** → 분석 → 결과.
- **전처리 4대 작업**: 결측치(채우거나 제거) / 이상치(확인 후 보정·제거) / 정규화(범위 통일) / 인코딩(범주형 → 숫자).
- **원본은 보존, 전처리한 사본을 사용**(되돌릴 수 없으므로).
- **차트 매칭**: 시간 변화=line / 두 변수 관계=scatter / **분포와 빈도=hist** / 범주별 비교=bar / **편차·이상치=boxplot**.
  - ⚠️ 함정: "분포와 빈도 = boxplot" → 틀림(hist).
- **히스토그램은 NaN 있으면 에러** → `dropna()` 후 그리기. 이상치 탐색은 `describe()`, 결측치 개수는 `isnull().sum()`.
- **특성 공학**: 기존 컬럼 조합으로 새 특성 생성(sibsp + parch = family_size).
- **원-핫 인코딩**: 범주 3개 이상을 0/1 컬럼으로 분리. 0,1,2 매핑은 모델이 **크기 관계로 오해**.

### [04] 머신러닝 기초
- **AI ⊃ ML ⊃ DL**. AI인데 ML이 아닌 것 = **규칙 기반·휴리스틱**(차집합 존재).
- **가설공간 = 후보 함수 전체 집합 / 모델 = 그중 선택된 함수 f 하나.** 학습 = D로 F에서 f를 고르는 과정.
- ⭐ **학습의 3요소 = 데이터 · 가설공간 · 선택 기준(손실 함수)**. (학습률·옵티마이저·검증셋은 3요소 아님)
- **손실**: 결과가 숫자 → 회귀 → **MSE** / 결과가 범주 → 분류 → **교차 엔트로피**.
- **MSE vs R²**: MSE는 0~∞·단위는 원래 단위의 제곱(→RMSE)·**구체적 오차 크기를 앎** / R²는 0~1·무단위·**모델 간 비교에 유리**하지만 오차 크기는 모름.
- **Accuracy**: 지시함수 I 사용. **불균형 데이터에서 99%도 무의미** → 혼동행렬·정밀도·재현율·F1 병행.
- **크로스 엔트로피 = −log(정답 확률)**. 0.9→0.11, 0.6→0.51, **0.1→2.30**. 정확도는 "맞음/틀림"만 세므로 **학습 신호로 못 씀**.
- **오버피팅**: 잡음까지 외움, 훈련↓ 테스트 U자형. **오버피팅 ≠ 분포 변화(distribution shift)** — 후자는 과적합 없어도 발생.
- **검증셋 접근**: 분할에 따라 **추정치가 매우 가변적**, 일부만 학습해 성능 과소평가. **K-fold**: 겹치지 않는 K개 그룹, MSE 평균. **LOOCV(K=n)은 비용이 커서 실무에선 K=5 or 10.**
- **K-means**: K를 **미리 지정해야 함**, 초기값 무작위 → **지역 최솟값** 위험 → 여러 번 시도.
- **계층적 군집**: 상향식 병합, **덴드로그램**을 잘라 K 결정, **계산량은 K-means보다 많음**, 스케일링 필요.

### [05] 회귀·신경망 기초
- **최소제곱법**: 잔차제곱합(RSS) 최소화, **닫힌 형태 해 존재**. 가중치·편향 = β₁·β₀.
- **상관 ≠ 인과** (아이스크림 ↔ 상어 사고: 공통 원인 = 더운 날씨). 유의성은 인과의 근거가 아니다.
- **로지스틱 회귀를 쓰는 이유**: 선형회귀는 **확률 범위(0~1)를 벗어남** → 시그모이드. **닫힌 형태 해 없음** → 경사하강법 필요.
- **MLE**: 우도 = 확률들의 **곱** → 계산·미분이 어려움 → **로그 우도**(덧셈으로 변환). 로그는 **단조함수**라 최대점 위치 불변.
- **얕은 신경망**: 은닉층 1개. ReLU가 **조각별 선형 함수**를 만듦. **보편적 근사 정리** — 히든 유닛이 충분하면 은닉층 1개로도 임의 연속함수 근사 가능.
- **깊은 신경망을 쓰는 이유**: 이론상 얕아도 되지만 **계산량 대비 표현 효율**이 낮다. 같은 6유닛이면 1-6-1보다 **1-3-3-1**이 표현력↑ (종이접기 비유).
- **최적화**: 컨벡스(U자, 두 점 잇는 직선이 위) vs **논컨벡스(로컬 미니마)**. **SGD**는 미니배치로 비용 절감, **지터리**하게 움직여 컨벡스에선 오히려 느릴 수 있으나 **노이즈가 안장점·로컬 미니마 탈출에 도움**.

### [06] 자연어 처리 기초
- **원-핫의 3대 문제**: 고차원 희소(메모리), **차원의 저주**(유클리드 거리가 거의 동일해짐), **직교라 유사도 측정 불가**(의미 정보 부족).
- **워드 임베딩**: "**주변 단어로 그 단어의 의미를 나타낸다**". 밀집·연속·**분산 표현**(한 차원 = 한 단어가 아님).
- **RNN**: 가변 길이 입력 처리, **모든 시점이 동일 가중치 공유**. hₜ = tanh(Whh·hₜ₋₁ + Wxh·xₜ). MLP는 고정 길이·순서 무시.
- **기울기 소실 결과**: 과거 시점 신호가 작아져 **장기 의존성은 못 배우고 단기만 포착** → 1997년 **LSTM**.
- **LSTM**: **셀 스테이트 = 장기(컨베이어 벨트) / 히든 스테이트 = 단기**. 게이트 3개(모두 시그모이드) — **포겟**(버릴지) · **인풋**(쓸지) · **아웃풋**(내보낼지).
- **N-gram**: 4-gram = 직전 3개. **장기 의존성 반영 불가**. 확률 = (문맥+단어)/문맥.
- **Seq2Seq**: 인코더가 **고정 차원 컨텍스트 벡터**로 요약 → 디코더 생성. **티처 포싱은 학습 단계 전용**(추론 땐 정답이 없어 에러 누적). 절충 = **스케줄드 샘플링**.
- **빔서치**: 후보 k개 유지, 점수 = **로그 확률의 합**, EOS 도달 시 완성 리스트에 추가.
- **Attention**: **병목 문제** 해결. Q = 디코더 히든, V = 인코더 전 시점 히든. 3단계 = 유사도 → **Softmax 분포** → **가중합**. 효능 = **해석 가능성**(어디에 집중했는지 시각화) + **정렬**(별도 정렬 모델 불필요).

### [07] 트랜스포머
- **RNN의 한계**: 장기 의존성(시퀀스 길이만큼 단계), **순전파·역전파 모두 순차라 병렬화 불가**.
- **Seq2Seq Attention = 입력↔출력 / Self-Attention = 같은 문장 내부.**
- **Q/K/V**: Q = 찾고 싶은 정보, **K = 스코어 계산용**, **V = 실제 출력 생성용**. 학습되는 Wq/Wk/Wv를 임베딩에 곱해 생성.
- **계산 3단계**: e = qᵢᵀ·kⱼ → Softmax(합 1) → oᵢ = Σ α·vⱼ. **자기 자신 포함.**
- **위치 인코딩**: **시누소이달**(주기 다른 sin·cos 합성) / **학습형 절대 위치 임베딩**. 임베딩에 **더해서** 입력.
- **마스킹 = −∞** (exp(−∞)=0). **0을 넣으면 exp(0)=1로 살아남아 마스킹 실패.**
- **멀티헤드**: 512 → 8헤드 × 64차원. **여러 관점 포착용**(병렬화용 아님). 차원을 나눠 갖는 것.
- **스케일링 √(d/h)**: 차원이 크면 내적이 커져 Softmax가 **지나치게 뾰족** → 기울기 소실. 목표는 **적당히 뾰족하게**.
- **잔차 연결**: 셀프 어텐션 뒤 **그리고 FFN 뒤 둘 다** 적용. 위치 정보가 깊은 층까지 유지되는 효과. **레이어 정규화는 별개의 안정화 기법**.
- **블록 구성**: 인코더 = MHA → FFN / 디코더 = **마스크드 MHA → 인코더-디코더 어텐션 → FFN**. 인코더-디코더 어텐션은 **Q = 디코더, K·V = 인코더**.
- **BERT**: 인코더, **MLM(토큰 15% 마스킹, 전체 vocab 교차 엔트로피)** + **NSP(IsNext/NotNext, [SEP])**. 다운스트림은 출력층만 얹으면 됨.
- **T5**: **Span Corruption**(연속 구간 제거 후 `<X>`,`<Y>`로 치환 → 복원) + **프리픽스**. 토큰 하나씩 가리는 건 BERT MLM.
- **인컨텍스트 러닝 = 가중치 업데이트 없이** 프롬프트만으로 수행(GPT-3에서 드러남). 트레이닝과 구분할 것.

### [08] 파운데이션 모델
- 정의: **데이터 1조 개 이상, 파라미터 10억 개 이상**으로 사전학습된 대규모 모델.
- **이전 = 태스크마다 데이터·학습 / 이후 = 프롬프트만으로**. 적응 방법 = 프롬프트 엔지니어링·제로샷·퓨샷·전이학습·파인튜닝(파인튜닝은 선택지 중 하나일 뿐).
- ⭐ **3요소 = 빅데이터(2025년 약 175ZB) + 자기지도학습 + 어텐션·트랜스포머.** 트랜스포머 채택은 **경험적 발견**이지 수학적 최적성 증명이 아니다.
- **자기지도학습**: 다음 토큰 예측처럼 **라벨링 없이 데이터 자체에서 시그널**을 뽑음. 기준은 "정답 유무"가 아니라 **사람이 라벨링했는가**. **디퓨전(노이즈→복원)도 자기지도학습.**
- **GPT-1 = 디코더·단방향 / BERT = 인코더·양방향.** **GPT-2 = GPT-1의 파라미터·데이터 각 10배**(BERT와 무관), 그럼에도 **언더피팅**.
- **연산량은 파라미터에 제곱 비례**(10배 → 100배). GPT-3 175B 학습 비용 ≈ 150억 원.
- **스케일링 법칙**: 카플란이 **작은 실험들의 추세선**으로 발견 → 학습 전 성능 예측 가능. **한계 = "다음 단어 예측을 얼마나 잘하나"의 법칙일 뿐**, 사업적 가치와는 별개.
- **창발성**: 1.3B 안 됨 → 13B 조금 → **175B에서 기울기 급증**. 추론 능력도 대표 사례. 대략 7B·1T 기준이나 **절대 기준 아님**.
- **폐쇄형(GPT·Claude·Gemini)** = API·블랙박스·성능 우수 / **개방형(LLaMA·DeepSeek·Mistral)** = 가중치 공개·자체 인프라 필요·성능은 다소 낮음·**디버깅 가능**.

### [09] 거대 언어모델 학습
- **GPT-3**: 3,000억 토큰·약 4TB·150억 원. **학습 방법은 그대로 다음 토큰 예측**, 달라진 건 규모. 125M부터 **순차적으로 키움**.
- **데이터 전략**: 커먼크롤이 구성의 **약 60%**지만, **저품질은 적게 반복 / 고품질은 많이 반복**. (구성 비율 ≠ 학습 반복 횟수)
- **사전학습 모델의 문제**: 올바르지 않은 응답 / 유해한 응답 / 지시를 못 알아들음 (+ 제일브레이킹).
- **정렬 학습(사후 학습)** = **지시 학습**(어떤 응답을 낼지) + **선호 학습**(어떤 응답이 더 선호되는지). 강화학습도 사후 학습의 핵심 도구.
- **지시 학습**: 입출력 포맷을 자연어로 통일. 목표는 태스크 암기가 아니라 **메타 지식(지시 이해 능력)**. 같은 태스크도 **템플릿을 여러 개** 주면 일반화↑.
- **FLAN**: **카테고리 레벨에서 학습/테스트 분리**(같은 카테고리를 봐서 잘하는 건지 구분하려고) → **제로샷 성능 크게 증가**.
- ⭐ **지시 학습 3관측**: ① 태스크 종류를 늘릴수록 성능↑ ② **모델이 클수록 좋음(8B 이하는 오히려 하락, 70B↑에서 개선 = 창발성)** ③ **자연어 지시**가 가장 효과적(데이터셋 이름 호출보다 나음).
- **RLHF 4단계**: Step 0 사전학습 → Step 1 지시 학습(**실제 유저 지시 수집 + 훈련된 주석자**) → Step 2 **보상 모델**(여러 응답에 사람이 **순위** 레이블 → 점수화, 순서가 정렬되도록 손실 설계) → Step 3 강화학습(점수 높은 응답을 더 생성). **발산 위험 때문에 사람이 중간 점검.**
- **효과**: 성능·안전성 모두 개선(유해 답변·할루시네이션 감소). **LLaMA 1 = 사전학습만 공개 / LLaMA 2 = RLHF 거친 Chat 모델 공개** → RLHF가 업계 표준.

### [11] CNN 구조
- **FCN**은 플래튼(32×32×3 = 3072) → 완전연결 / **CNN은 3차원 구조를 보존**해 지역 패턴 포착. 합성곱 연산 자체는 1960년대부터 있던 것.
- 필터는 **입력 채널과 같은 깊이**. 필터가 **온전히 겹치는 위치부터** 적용 → 가장자리 버려짐 → **패딩**(제로/리플리케이트). **활성화 맵 해상도는 필터 크기에 반비례.**
- **출력 채널 수 = 필터 개수.** 필터를 늘려도 **공간 해상도는 그대로 줄어든다.**
- **저차원 레이어 = 지역적 패턴 / 고차원 레이어 = 오브젝트 수준.** 선형모델은 클래스당 템플릿 1개뿐 → 변형에 취약.
- **수용영역 넓히는 법 4가지**: 깊게 쌓기 / 풀링 / 스트라이드 / **다이얼레이티드 컨볼루션**. (**배치 정규화는 아님**)
- **풀링**: **학습 파라미터 없음**, 맥스 풀링, 연산량↓ + 미세 이동에 강건. 한계 = **해상도·정보 손실**.
- **스트라이드 합성곱**: 풀링과 합성곱을 **하나로 대체**, 정보 손실이 풀링보다 적음. **최신 CNN의 추세**.
- **변천사**: 2012 **AlexNet 16.4%** (급격한 개선의 기점) → 2015 **ResNet 152층 3.6%** (사람 5.1% 최초 돌파) → 2017 **SENet 2.3%**.
- **AlexNet**: conv 5 + FC 3 (총 8층), 입력 227×227×3, 출력 1000, **VRAM 3GB 한계로 GPU 2개 병렬**, 필터 크기 제각각(애드혹).
- ⭐ **집중 분포**: **메모리(활성화) = 초기 레이어 / 파라미터 = FC 레이어 / 연산량(FLOPs) = Conv 레이어.**
- **VGG**: **3×3 고정(stride 1, padding 1) + 2×2 풀링 + 풀링 후 채널 2배**. **3×3 두 번 = 5×5 한 번**의 수용영역인데 파라미터는 **18C² < 25C²**이고 더 깊어짐. 단점 = 전체 규모가 무거움(메모리 25배, 연산 19.4배).
- **ResNet**: **56층이 20층보다 훈련 에러가 높은 과소적합** → 잔차 블록("적어도 얕은 모델만큼은 보장"). 입력·출력 크기가 같아야 함. **1×1 conv = 채널 수 조절**. **보틀넥 17HWC² < 일반 18HWC².** 레시피에 **드롭아웃 없음**(BN·He 초기화·SGD+모멘텀 0.9 사용). ResNet-50 = 보틀넥 버전.
- **MobileNet**: `9C²HW` → **깊이별(3×3, 채널별 독립) 9CHW + 화소별(1×1, 채널 혼합) C²HW**.

### [12] 비전 트랜스포머
- **CNN의 한계**: 시퀀스 처리 어려움, **장거리 의존성 부족**(레이어를 쌓아도 부족), 위치 정보 손실.
- **기울기 폭발/소실**: 같은 W를 반복해서 곱하는 구조. 특이값 **1보다 크면 폭발, 작으면 소실**. **클리핑은 폭발만** 해결(소실엔 무력).
- **LSTM이 기울기 소실에 강한 이유 = 셀 상태 업데이트의 "+"(덧셈) 연산** → **ResNet 잔차 연결과 같은 원리**(게이트에 시그모이드를 쓰는 것과는 별개).
- **정보 희석**: 망각 게이트가 **조금씩 계속 줄여** 누적됨 → 어느 시점 정보였는지 짚어내기 어려움(한 번에 끊기는 게 아님).
- **이미지 자기유사성**: 주변 픽셀 평균은 **블러** → 멀리 있어도 **비슷한 패치**를 참조. 어텐션은 라벨 없이도 유사 영역을 묶는 **클러스터링 효과**.
- **모델별 특성**: CNN(지역 강, 장거리 약, 순서 불가) / RNN(장거리 어려움, 기울기 문제) / LSTM(장거리 가능, **정보 희석**) / 어텐션(**장거리 탁월·희석 없음, 순서 개념 없음**).
- **ViT 위치 인코딩 4종**: 학습형 / **사인파(주기 다른 사인 합성)** / 상대 위치(해상도 가변 OK, **절대 위치 어려움**) / **RoPE(회전, 절대 위치 소실, 연산량↑)**.
- **ViT 인코더**: 정규화 → MHA → 정규화 → FFN, **L개(보통 12개 이상)** 반복 후 **MLP 헤드**. 헤드마다 형태·색·위치 등 다른 관점.
- **ViT vs CNN**: **데이터가 많을수록 ViT는 계속 상승, CNN(ResNet)은 정체.** ViT는 파라미터가 많아 **정규화·데이터 증강이 매우 중요**. 단점 = 소규모 데이터에선 CNN보다 약함, 자원 요구 큼, 토큰 수 제한.
- **Swin**: 윈도우 내부만 어텐션 → 다음 층에서 **윈도우를 한 칸 이동(shifted)** → 결과적으로 전역 효과. (전역 직접 어텐션은 **비용이 커서** 피한 것)
- **DINOv3**(Meta, 자기지도, LVD-1.7B, **가중치 공개**) vs **ViT-22B**(Google, **지도학습·비공개 데이터·재현 불가**).

### [13] 이미지 모델 학습 방법
- **활성화 함수**: Sigmoid(0~1, 포화·항상 양수·exp 비쌈) / Tanh(−1~1, 여전히 포화) / **ReLU(양의 영역 포화 없음, dead ReLU)** / Leaky ReLU(음수에도 작은 기울기, **항상 우세하진 않음**) / ELU(평균 0 근처, exp 비쌈). **결론: 일단 ReLU.** 시그모이드·tanh는 **게이트 같은 특수 구조**에 적합.
- **전처리**: **평균 0, 표준편차 1**. 학습·검증·테스트에 **동일 적용**. **AlexNet = 평균 이미지 빼기 / VGG = 채널별 평균·표준편차**(동일하지 않음).
- **초기화**: 0으로 두면 **학습 자체가 안 됨**(대칭성). **Xavier std = 1/√dim**(입출력 대칭 가정) / **ReLU에는 He std = √(2/dim)**. ResNet 잔차 블록은 **1st conv = He, 2nd conv = 0**.
- **정규화(규제)**: 필요 신호 = **훈련 오차↓인데 검증 오차↑**. **L2(릿지/Weight Decay) = 제곱 패널티로 큰 값 억제 / L1(라쏘) = 절댓값 패널티로 0을 만듦(희소성·특성 선택)** / 엘라스틱 넷. 규제만 극단화하면 **아무것도 안 하는 모델**이 되므로 원 목표와 균형.
- **드롭아웃**: 매 스텝 다른 부분망 → **앙상블 효과**. **FCN에 주로**, CNN·BN 적용 모델에는 비선호. **테스트 시엔 전부 사용**하고 학습 때 **1/(1−p) 스케일링**.
- **학습률 = 가장 중요한 하이퍼파라미터.** 스케줄링은 **크게 시작해 작게**: 계단식(실무 다용, 변경 시점 불명확) / **코사인(빈번)** / 선형(사전학습·파인튜닝).
- **하이퍼파라미터**: 사람이 정하는 값(학습률·배치·에폭·옵티마이저·깊이·드롭아웃 비율…). **배치 작으면 정규화, 크면 안정성.** **얼리 스타핑 = 검증 손실 모니터링.**
- **탐색**: 그리드 서치는 조합이 많으면 불리(불필요한 축 낭비) → **랜덤 탐색 선호**.
- ⭐ **디버깅 5단계**: ① 초기 손실 ≈ **log(클래스 수)** 확인 → ② 작은 샘플로 **정확도 100% 과적합** 시켜보기 → ③ 손실 폭발 시 **학습률↓·초기화 변경**(100 이터, 1e-1~1e-4 로그 스케일) → ④ 후보 조합 **1~5 에폭만** 짧게 비교(**검증 로스** 기준) → ⑤ 10~20 에폭 추가.
- **손실 곡선 해석**: 초반 정체 = 초기화 문제 / 검증 정확도 하락 = 과적합 / 학습·검증 차이가 거의 없음 = **표현력 부족 → 더 큰 모델로 더 오래**.

### [14] 거대 시각 언어 모델
- **파운데이션 모델**: **"마케팅·트렌드 용어에 가깝다"**, **비지도(자기지도) 학습 기반이 다수**, 자연어 기반의 **한정되지 않은 대상** 인식(범용성).
- **제로샷 = 이미 가진 배경지식 활용 / 퓨샷 = 예시 몇 개 보여주고 적용.**
- **VLM 등장 배경**: 지능 = 지각 + 인지. ChatGPT 이후 인지는 인간 수준 근접했으나 현실 이해 부족 → **"LLM에게 눈을 달자"**. 실무적으로는 **MCP 같은 표준이 레거시에 적용 안 되어 화면 캡처(이미지) 방식이 선호**된 배경도 있음.
- **CLIP**: **4억 쌍**(alt 태그 수집·정제), 텍스트 인코더 = 트랜스포머 / 이미지 인코더 = **ViT-B 또는 ResNet-50**, **인코더-온리**(벡터만 필요해서). 실사용은 **이미지 인코더만 떼어 LLM에 붙임** = VLM의 "눈".
- **대조 학습**: 짝이 맞으면 **코사인 유사도(방향)** 를 키우고 아니면 줄임. **두 인코더는 합쳐지지 않고 출력 공간만 공유.** **I→T, T→I 양방향** 학습, **τ(temperature)** 가 낮으면 확률이 몰림.
- **SigLIP**: Softmax는 **이미 충분히 먼 음성 쌍까지 계속 밀어내느라** 에너지 낭비 → **시그모이드로 쌍마다 독립 이진 분류**.
- **멀티모달 정합 2가지**: **변환(Translating)** = A → 신경망 → B / **정렬(Matching)** = 각각 인코더 → 같은 공간. **CLIP은 정렬 방식.**
- **LLaVA**: 사전학습된 이미지 인코더 + 텍스트 디코더 사이에 **선형층 한 칸만 두고 그것만 학습**. 데이터는 **COCO + ChatGPT 자동 역질의**(대화 / 자세한 설명 / 복잡한 추론). **파인튜닝 단계에선 LM도 함께, FP16 양자화로 메모리 최적화.**
- **Qwen-VL 3단계**: Stage 1(**QwenLM 고정**, 저화질) → Stage 2(QwenLM 포함, 고화질) → Stage 3(**ViT 고정**, SFT). **Qwen2-VL** = 임의 해상도·문서 파싱·객체 그라운딩. **Qwen2.5-Omni** = 띵커/토커 구조.
- **Set of Mark**: 세그멘테이션 모델로 표시를 찍어 VLM의 부족한 시각 능력 보완(**비주얼 프롬프팅**). **AnomalyGPT** = 제조 결함 탐지 챗봇. **VLA** = 출력이 **행동**.

### [15] VLM 서빙·생성 모델
- **스몰 VLM**: **SmolVLM**(1.7B + **SigLIP**, VRAM 5GB) / **MoonDream 0.5B**(8bit 479MB, 실행 996MB) / **Gemini Nano**(1.8B·3.25B).
- **양자화**: 크기·메모리·속도는 개선, **정확도는 소폭 하락**(같이 좋아지지 않음).
- **한국어 토큰화**: 영어가 최대 **2.5배** 밀도 → 비영어권은 컨텍스트 낭비. ⚠️ **언어의 한계가 아니라 토크나이저 설계 문제.**
- **LMDeploy**: 압축·배포·서빙 툴킷 — **양자화도 제공**, 분산 서빙, 높은 호환성.
- **이미지 파운데이션 모델**: **SAM**(10억 장, 공개) / **Grounding DINO**(텍스트로 물체 지정) / **Grounded SAM**(결합) / **SAMURAI**(트래킹).
- **생성 모델링**: 데이터는 **분포의 샘플일 뿐** → 목표는 p_data를 **p_model로 근사**하는 것.
- **DDPM**: 가우시안 노이즈에서 점진적으로 제거. 학습은 **노이즈를 예측하는 문제**로 환원.
- **LDM**: 픽셀 대신 **저차원 latent**에서 디퓨전 → **효율과 품질을 동시에** 개선. **Stable Diffusion(2022)** 에서 소개(미드저니 아님). 구조 = 인코더 → latent 노이즈 추가/제거 → 디코더.
- **Denoising U-Net + 크로스 어텐션 = 조건부 생성의 핵심**(텍스트 특징 → 이미지 특징 점진 개선).
- **응용**: **ControlNet**(조건 기반 생성) / **Marigold**(단안 깊이, **합성 데이터 파인튜닝, 2.5D**) / **Sapiens**(Meta, 인간 형태, **3,000만 장**).
- **비디오**: **Sora = 월드 모델** 가능성 / **Veo 3 = 소리까지 동시 생성** / Luma Labs = 편집.
- **파인튜닝**: 적은 데이터·적은 리소스로 좋은 성능, 프롬프트 예제보다 훨씬 많은 예제 학습. **학습률이 너무 낮으면 느릴 뿐 아니라 로컬 미니마에 빠질 수 있음**(낮을수록 안전이 아님).
- **PEFT 3종**: **프롬프트 디자인**(사람이 작성, 효율↑ 성능 제한) / **프롬프트 튜닝(2021)** = **가상 토큰 임베딩만 학습**, 본체 고정이라 지식 손실 없음, 단점은 **사람이 해석 불가** / **LoRA** = 저랭크 어댑터 모듈 삽입. ⚠️ **LoRA만 있는 게 아니다.**
- **지식 증류**: 선생님의 **소프트 라벨**을 학생이 모방. ⭐ **여기서 소프트 라벨 = Softmax 통과 전의 값, 즉 로짓.**
- **InstructPix2Pix**: 상세 설명 없이 **명령만으로 편집**. **기존 범용 데이터셋을 활용해 (지시, 편집 전, 편집 후) 학습셋을 자동 생성** → 지도학습 문제로 전환.
- **서빙**: 배포(REST API·gRPC) + 운영 보조(스케일링·라우팅·모니터링). **허깅페이스 Inference API**(요청 횟수 제한) / **Gradio**(웹 UI) / 모바일은 **ONNX**. ⚠️ **모든 게시 모델이 배포를 지원하지는 않는다.**
