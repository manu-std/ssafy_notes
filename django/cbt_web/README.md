# Django CBT 웹 페이지 소스

Django 1~10단원 CBT 문제(단원당 30문항, 총 300문항)를 문제은행 텍스트에서 만들어 내는 소스와 빌드 스크립트.

- 웹에서 풀기: https://claude.ai/artifact/TenZ4Cw6CFm3hhEbGEgbeb
- 마크다운으로 보기: [`../문제/`](../문제/) (`NN_..._CBT.md`, 빌드가 생성)

## 파일

| 파일 | 역할 |
|---|---|
| `bank_01_05.txt`, `bank_06_10.txt` | 기본 문제(각 단원 1~20번) 문제은행 원본 |
| `bank_traps.txt` | 함정 문제(각 단원 21~30번) 문제은행 원본 |
| `answer_key.json` | 정답 위치표. **문제를 쓰기 전에 먼저 생성**하고 문제를 그 위치에 맞춰 작성했다 |
| `make_key.py` | 기본 문제 위치표 생성 (시드 20261108, 단원당 ①~④ 각 5개, 3연속 금지) |
| `make_key_extra.py` | 함정 문제 위치표 추가 (시드 20261109, 단원당 3·3·2·2개, 10단원 합계 각 25개) |
| `build.py` | 문제은행 파싱 → 검증 → 마크다운 10개 + `django_cbt.html` 생성 |
| `template.html` | CBT 페이지 템플릿. `__BANK_JSON__` 자리에 문제 데이터가 들어간다 |
| `django_cbt.html` | 빌드 결과물. 문제 데이터가 내장된 단일 HTML |

## 빌드

```bash
cd django/cbt_web
python -I build.py . ../문제
```

- 결과: `../문제/NN_..._CBT.md` 10개, `django_cbt.html`, `questions.json`(중간 산출물, 커밋 안 함)
- 검증 항목: 단원당 30문항 번호 연속, 보기 4개·중복 없음, 해설 있음, **정답 번호 == answer_key.json 위치**
- 하나라도 어긋나면 `VALIDATION FAILED`와 문항 번호를 출력하고 아무것도 쓰지 않는다
- "정답이 가장 긴 보기인 비율"도 출력한다 (무작위 기대값 25%, 현재 24%)

위치표를 처음부터 다시 만들 때는 반드시 `make_key.py` → `make_key_extra.py` 순서로 실행한다 (`make_key.py`는 파일을 새로 쓰므로 함정 위치표가 지워진다). 시드가 고정이라 같은 표가 다시 나온다.

## 문제은행 형식

```text
@@ 05            ← 단원
# 21             ← 문항 번호
Q 문제 첫 줄      ← 이어지는 줄과 ``` 코드블록까지 문제 본문
1 보기 ①
2 보기 ②
3 보기 ③
4 보기 ④
A 2              ← 정답 번호 (위치표와 같아야 빌드 통과)
E 해설 한 줄
```

본문·보기·해설 안에서 `` `코드` ``, `**굵게**`, ```` ``` ```` 코드블록을 쓸 수 있다.

## 페이지 기능 메모

- 시험 모드(제출 후 채점) / 연습 모드(즉시 정답·해설), 문항 범위(전체 / 기본 1~20 / 함정 21~30), 순서 섞기
- PC: 문제 + 오른쪽 OMR 답안표기란 / 폰(899px 이하): 1단 + 하단 이전·답안표·다음 바, 답안표는 바텀시트
- 오답 기록·설정은 `localStorage`(`django-cbt:v1`)에 저장 → 브라우저마다 따로다
- 오답노트 `.md` 저장은 claude.ai의 `downloads` 기능(publish 시 `capabilities: {downloads: true}`)을 쓴다. 로컬에서 HTML을 직접 열면 저장 버튼은 숨겨지고 마크다운 복사만 된다
- 문항 순서 섞기는 있지만 **보기 순서는 섞지 않는다** (정답 위치표를 지키기 위해)
